# Nexus Assistant Web App

A minimal dark dashboard web app for a Hindi-English coding assistant.

## Features

- Dashboard with sidebar, chat area, and history panel
- Black and yellow theme with smooth transitions
- 3D loading screen and cursor glow effect
- Local chat history saved in browser storage
- Editable system prompt and company info
- Saved prompts and assistant style controls

## Files

- `index.html` — main UI structure
- `styles.css` — theme and animations
- `script.js` — local state, history, and UI behavior

## Run locally

Open `index.html` in your browser.

## Next steps

To connect to a real API backend, replace `simulateAssistantResponse()` in `script.js` with a fetch call to your hosted model API.
